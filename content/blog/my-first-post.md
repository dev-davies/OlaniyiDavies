## Building a Markdown Blog

Welcome to the very first post on this blog! This project uses a modern stack featuring Vue 3, Vite, and specialized Vite plugins to process markdown files just like standard Vue components. It's a fantastic way to blend the simplicity of markdown with the dynamic capabilities of Vue.

By extracting the YAML frontmatter, we can easily display metadata—such as the title, date, and estimated reading time—directly in our layout before rendering the actual post body.
